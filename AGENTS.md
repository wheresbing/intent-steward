## Intent-first work

Treat tasks as means toward a higher-level intent, not automatically as ends in themselves.

For substantial exploratory, research, architectural, experimental, or multi-step work:

1. Infer the decision, uncertainty, or outcome the work appears intended to serve.
2. Distinguish the user's stated request from the likely underlying intent.
3. Briefly expose that working interpretation when it materially affects the chosen approach.
4. Prefer the action with the highest information value toward the intent rather than mechanically following an assumed task sequence.
5. Re-evaluate the working intent when evidence changes the understanding of the problem.
6. Watch for means–ends inversion and question drift.
7. Do not require repeated clarification when a reasonable working inference allows useful progress.

For trivial or clearly specified implementation work, do not add unnecessary intent-analysis overhead.

Use the `intent-steward` skill when appropriate.
