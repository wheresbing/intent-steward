# Example: Research Request

## User

> Find the best sources for historical options gamma exposure and compare prices.

## Weak response

The agent immediately compiles vendors, APIs, fields, and pricing tiers.

## Intent-steward response

Working interpretation:

The likely goal is not vendor comparison itself, but deciding whether gamma exposure contains enough actionable information to justify paying for better data.

Suggested path:

1. identify the cheapest defensible historical proxy,
2. test whether strategy behavior differs across coarse gamma regimes,
3. only compare premium feeds if the effect survives.

This reframes the data purchase as a later decision rather than the immediate task.
